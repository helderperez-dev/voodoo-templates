# Voodoo application

This project was generated by `voodoo new` and targets Framework 3.2.x on
Python 3.12 or newer.

## Development

```bash
cp .env.example .env
voodoo dev
```

Install the optional quality tools when working on the generated project:

```bash
python -m pip install -e ".[dev]"
ruff check app tests
mypy app
pytest -q
```

The generated repository also includes a Chromium browser/accessibility smoke
workflow under `.github/workflows/quality.yml`; it starts the app and checks the
semantic landing-page contract.

The default development profile creates a durable Store at
`.voodoo/application.vstore`. Do not commit `.env` or Store files.

## Production checklist

Set `VOODOO_ENV=production`, provide a unique `VOODOO_SECRET_KEY` with at least
32 characters, configure explicit `VOODOO_CORS_ORIGINS`, keep CSRF enabled for
cookie authentication, and run `voodoo doctor` before starting the service.
Production Profile 1 supports one Runtime process and one Store writer; use
the documented backup and restore workflow before upgrades.
